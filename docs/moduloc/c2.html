Módulo C – Requisitos, Valor e Planejamento

C2 – User Stories, Backlog e Planejamento Incremental

1. User Stories como Instrumento Conceitual

User Stories não são descrições técnicas detalhadas. São instrumentos de expressão de valor.

Como [perfil], quero [ação], para [benefício].

Essa estrutura garante foco em quem recebe valor, qual ação será realizada e qual resultado se pretende alcançar.

2. Critérios de Aceite

Critérios de aceite estabelecem quando uma história pode ser considerada concluída. Devem ser verificáveis e objetivos.

História sem critério de aceite é ambiguidade institucional.

5. Planejamento Incremental

Planejamento rígido pressupõe previsibilidade absoluta. Planejamento adaptativo reconhece incerteza.

Planejar incrementalmente significa decidir com base em valor entregue.
